# 毛概课程笔记
## 绪论
- 马克思主义中国化时代化的科学内涵是什么？
- 1.运用马克思主义的立场、观点与方法，观察时代、把握时代、引领时代，解决中国革命、建设、改革中的实际问题
- 2.总结与提炼中国革命、建设、改革的实践经验并将其上升为理论，不断丰富和发展马克思主义的理论宝库，赋予马克思主义以新的时代内涵
- 3.运用中国人民喜闻乐见的民族语言来阐述马克思主义，使其植根于中国优秀传统文化的土壤之中，具有中国特色、中国风格、中国气派
- 如何认识马克思主义中国化时代化理论成果及其相互关系？
- 1.马克思主义中国化时代化理论成果的关系是一脉相承又与时俱进的
- 2.一方面，毛泽东思想所蕴含的马克思主义的立场、观点和方法，为中国特色社会主义理论体系提供了基本遵循
- 3.另一方面，中国特色社会主义理论体系在新的历史条件下进一步丰富和发展了毛泽东思想
- 4.毛泽东思想和中国特色社会主义理论体系，都是马克思列宁主义在中国的运用与发展，都是以独创性的理论成果丰富和发展了马克思主义的理论宝库
## 第一章
- 毛泽东思想的主题是什么？主要内容有哪些？
- 主题：中国革命与建设
- 内容：新民主主义革命理论、社会主义革命和社会主义建设理论、革命军队建设和军事战略理论、政策和策略的理论、思想政治工作和文化工作的理论、党的建设理论
- 毛泽东思想的活的灵魂包括哪些方面？如何坚持毛泽东思想活的灵魂？
- 三个方面:实事求是、群众路线、独立自主
- 一、坚持实事求是
- 1.就是要深入实际了解事物的本来面貌
- 2.就是要清醒认识和准确把握我国的基本国情
- 3.就是要不断推进实践基础上的理论创新
- 二、坚持群众路线
- 1.就是一切为了群众、一切依靠群众，从群众中来，到群众中去，把党的正确主张变为群众的自觉行动
- 2.就是要坚持人民是推动历史发展的根本力量
- 3.就是要坚持全心全意为人民服务的根本宗旨
- 4.就是要保持党同人民群众的血肉联系
- 三、坚持独立自主
- 1.就是要在马克思列宁主义一般原则指导下，深入调查研究，掌握本国国情，走自己的路
- 2.就是要坚持中国的事情必须由中国人民自己作主张、自己来处理
- 3.就是要坚持独立自主的和平外交政策
- 如何认识毛泽东思想的历史地位？
- 1.马克思主义中国化时代化的第一个重大理论成果
- 2.中国革命和建设的科学指南
- 3.中国共产党和中国人民宝贵的精神财富
