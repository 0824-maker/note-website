m是否为素数

除了1和本身以外不能被其他数所整除

```c
如果m能被2整除为真跳出=》if(m%2==0)break
```

如果m能被3整除为真跳出

如果m能被i整除为真跳出

如果m能被sqrt（m）整除为真跳出

```c
m=2; i=2;flag=1;
while(i<=sqrt(m)&&flag==1)
{if(m%i==0)flag=5;
i=i+1;}
if(flag==1)printf("%d\n",m);
```

C中，语句比如以分号结束，而分号并不一定是语句的结束标记。

c程序是由函数构成，函数是由语句组成。

main函数是程序的入口，不是c的关键字。

C中四种类型常量整形、实型、字符、字符串；

三种类型的变量整形、实型、字符

短整型2个字节，16个二进制位，一共有65536种可能性

一个字符常量就可以看成一个字节的整形常量，一个字符变量就可以看成一个字节的整形变量

一个西文字符一个字节存储，共8个二进制位

一个八进制基数0~7，可以用3个二进制位表示

一个16进制基数0~F，可以用4个二进制位表示

一个西文字符用八进制表示，需要8/3~3个八进制位

一个西文字符用16进制表示，需要8/4=2个16进制位

‘A’的ASCII码是65,八进制是101，16进制是41
